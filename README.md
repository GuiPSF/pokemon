# Pokémon APP

### Description:

My project is an two-page application that on the first one you can see details of the pokémon you choose, like a pokédex. You can see stats like health, attack, sp. attack, defense, and others! The second is a minigame, like the one that shows on the middle of the pokémon episodes "Who's that Pokémon?". The game will only contain Pokémons of the generations 1, 2 and 3 (it can be changed). A sillhuete of the specific pokémon will pop on the screen, and you need to write down the right name of the Pokémon (letter by letter!). After that, if you type it right, a green sign will show on the screen and your points will be increased. The pokémon photo will be visible for 1 second, and after that, the next pokémon will take place. If you write the name wrong, a red sign woll show on the screen, and you'll not gain any points. Again, the photo of the pokémon will be visible, and then the next pokémon will appear.
